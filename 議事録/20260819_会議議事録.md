## 中長期ロードマップ

### Phase 1：実証（2026年10月〜）

**目的**: 9軸評価アプリそのものを検証する

| 確認項目 | 内容 |
|---|---|
| 評価軸 | 9軸で十分か |
| 評価基準 | 4段階が機能するか |
| 継続率 | 学生が使い続けるか |
| メンター負荷 | 評価が負担にならないか |
| データ品質 | 気づきが取得できるか |

### Phase 2：見える化（2026年冬〜）

- 学生：成長推移・学習履歴・振り返り履歴・強み・弱み
- メンター：フィードバック傾向・評価傾向・学生とのギャップ
- プロジェクト：活動量・会議回数・参加率・課題解決状況
- 思考：学生「何を考えたか・なぜそう判断したか」/メンター「なぜその評価をしたか」の蓄積

### Phase 3：気づき

- 学生：自分の強み・成長軸・改善点への気づき
- メンター：使いづらい評価軸・伸びる学生の特徴への気づき
- 大学・企業：PBLによる成長傾向・人材育成のヒント

### Phase 4：成長

「レベルは？」→「**どうすればレベルを上げられる？**」へ移行  
例：Lv2→Lv3になるための行動例を提示

## 将来構想：学生ポートフォリオ

各学生のPBL履歴・活動履歴・成長推移・フィードバック履歴・成果物を統合し、  
就職・インターン・地域連携に活用できるポートフォリオとして機能させる。

**企業向けキーワード（佐藤教授より）**
- 地域課題の見える化
- 社内課題の見える化
- 採用の見える化（思考・行動履歴・成長履歴）
- 人材育成の見える化（プロセス評価・成長評価）
